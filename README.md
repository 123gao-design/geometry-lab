## 运行

需要 Node.js ≥ 18。本机没有全局 node 且无 sudo 时，装一份用户级的即可：

```bash
# 用户级安装 node（系统已有 node 可跳过）
mkdir -p ~/apps && cd ~/apps
curl -sL -o node.tar.xz https://registry.npmmirror.com/-/binary/node/v22.20.0/node-v22.20.0-linux-x64.tar.xz
tar -xJf node.tar.xz && rm node.tar.xz
ln -sfn ~/apps/node-v22.20.0-linux-x64 ~/apps/node
export PATH="$HOME/apps/node/bin:$PATH"   # 建议写进 ~/.bashrc
```

然后：

```bash
cd geometry-lab
npm install        # 依赖已配置 npmmirror 镜像（见 .npmrc）
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # 产出 dist/ —— 纯静态，可 file:// 直接打开（hash 路由 + base:'./'）
npm run preview    # 本地预览构建产物
```

## 桌面端（Tauri 2）

同一份 Vite 产物装进系统 WebView，不打 Chromium。三平台出包走 GitHub Actions（`.github/workflows/release.yml`）：推一个 `v*` 标签（或在 Actions 页手动触发），矩阵跑 windows / macos(arm+x64) / ubuntu，产物挂到 draft Release——Windows 是 NSIS 每用户安装的 `-setup.exe`（自带 WebView2 引导），macOS 按芯片选 `.dmg`，Linux 出 `.deb` 与 `.AppImage`。

本地要跑桌面壳（调试或出包）需要 Rust 工具链（[rustup](https://rustup.rs)）：

```bash
npm run icon       # 一次性：生成 src-tauri/icons/ 全套图标（零依赖脚本，照 favicon 的构图）
npm run tauri dev  # 桌面壳 + Vite 开发服务器热更新
npm run tauri build  # 本平台出包，产物在 src-tauri/target/release/bundle/
```

配置都在 `src-tauri/tauri.conf.json`：窗口 1440×900、中文标题；`productName` 用 ASCII（GeometryLab），安装器对中文包名挑剔；`frontendDist` 指向 `../dist`，构建前自动跑 `npm run build`。壳里已挂 dialog / fs 两个插件，供后续统一保存入口（`src/lib/save.js`）桥接到系统文件对话框；网页端不受任何影响，两轨并存。

三条已知边界：macOS 的 WKWebView 里 MediaRecorder 不可靠、没有 File System Access（录像与存目录以浏览器端为准）；Linux 的 WebKitGTK 偶发 WebGL 黑屏，启动加 `WEBKIT_DISABLE_DMABUF_RENDERER=1` 可解；安装包未做代码签名，macOS 首次打开要右键→打开，Windows SmartScreen 选「仍要运行」。

## 如何扩展

**新增一个演示画板**（最常用）：

1. 在 `src/boards/<模块>/<子专题分组>/` 下新建模块：

   ```js
   import { Board, mk, V } from '../../../lib/board.js';
   export function createBoard(root) {
     const B = new Board(root, 800, 500);
     // B.handle(...) B.btn(...) B.chip(...) B.renderFn = () => {...}
     B.render();
     return B;
   }
   ```

2. 在目标章节的 view 里挂载：`<BoardMount :factory="createBoard" />` + `<div class="cap">图注</div>`。

**新增一个章节**（如某模块的某个子专题）：
`src/views/<模块>/<分组>/` 下新建页面 → `router.js` 加路由 → 模块主页（如 `ConicsHome.vue`）加卡片。若章节自成系列（多讲），在分组目录里放一个 `xxxnav.js` 元数据（参考 `views/conics/definitions/defnav.js` 与 `def1.vue`），给 `ChPage` 传 `chapters` / `base` / `no` 属性即可获得独立的章节导航条。

**新增一个子专题分组**（views 与 boards 同构）：
`src/views/<模块>/<新分组>/` + `src/boards/<模块>/<新分组>/` 两套目录 → 路由用新的 URL 段（如 `/conics/xxx1`）→ 模块主页加一组卡片。

**新增一个模块大类**（如函数、数列）：
`src/views/<模块>/<模块>Home.vue` + `src/boards/<模块>/` → `router.js` 加 `/<模块>` 路由与各章路由 → `Home.vue` 目录里对应卡片去掉 `dim`、改成 `router-link`。完整约定见 `CLAUDE.md`。

**新增一个专题大类**：
`views/` 下新建专题主页 → `router.js` 加 `/xxx` 路由 → `Home.vue` 目录里对应卡片去掉 `dim`、改成 `router-link`。

**高等数学的模块**：
先往 `src/lib/higherplan.js` 的 `HIGHER` 里加一条（或改现有条目）——模块 `slug`、模块名、首页卡片一句话、模块简介、子专题分组与章目；`views/higher/HigherHome.vue` 会自己渲染，首页「二 · 高等数学」那张卡也自动出现。真正开写一章时，按上面的「新增一个模块大类」走，并把 `router.js` 里那条单段模块路由拆成 `/slug/xx1…`；`/projective` 已被旧路径重定向占用，射影几何用 `/projgeom`。九个模块已全部按这条路开写完毕（`Calc1Home.vue`、`SpacegeomHome.vue`、`Calc2Home.vue`、`ComplexvarHome.vue`、`NumtheoryHome.vue`、`TopologyHome.vue`、`FractalHome.vue`、`ProjgeomHome.vue`、`AlgebraHome.vue`、`modnav.js` 的 SPEC 一行、各子专题 nav 文件与路由），`views/higher/HigherHome.vue` 因此退出使用，只留作新模块的模板。

画板引擎要点：数学工具统一从 `../lib/board.js` 导入（它 re-export 了 `math.js`）；动画一律用 `B.raf(fn)`（销毁时自动 cancel，防止离开页面后空转）；颜色写语义色号（`'#5cadff'`、`'#ffd166'` 等），亮暗主题自动映射；画板内元素自动被 viewBox 级 clipPath 裁剪。

## 主题

右上角 🎨 按钮点开**圆角面板**任选八套配色（不再循环盲切）：**暗夜**（深蓝画布风）、**暮夜**（暗色渐变：深夜蓝→暗紫）、**纸面**（学术纸面风：米白底、衬线标题）、**青蓝 / 暖沙 / 薄荷 / 樱粉 / 云紫**（五套浅色渐变底 —— 冷青蓝、暖沙米黄、薄荷青绿、樱粉、薰衣草紫；页面背景、卡片与导航随主题换色，画板内元素与浅色家族共用一套色映射）。面板里色卡为**圆形**、下写名字，一行四枚、放不下自动分行，当前主题描边打勾；点外部、Esc 或滚动页面收起。面板底部是「✨ 背景光影」开关：页面背景三团主题色柔光大幅漂移、明暗呼吸（周期 11–17 秒的移动 + 5–7 秒的亮度脉动，负延迟让页面一打开就处于动画中途；默认开，写 localStorage 偏好；打印与系统「减弱动态效果」下自动隐藏）。主题与光影偏好都持久化在 localStorage，首次访问跟随系统 `prefers-color-scheme`；打印时自动临时切到纸面并复原（不覆盖所选主题）。实现：`board.js` 的 `THEMES` + `applyTheme()` + `initAnim()`（`html.light` 类为浅色家族共用开关，`html.no-anim` 关光影，`data-theme` 区分各主题页面配色，见 `global.css`）；面板挂 `body` 用 `position:fixed`，坐标在展开时按按钮实时计算——导航条 `.in` 的 `overflow-x:auto` 会把挂在里面的绝对定位面板裁成贴边一条。
