# 交互画板评审与改进记录

2026-11-23。优先修正画板中与定义、公式不一致的读数，再用圆锥曲线 D4 验证排版和标注方式。本轮已实现下列九项，原问题、设计和验收条件保留供后续复查。

## 图形与知识点的修改清单

### 圆锥曲线 D4 与 D4c

- [x] **D4 保持探针在曲线上。** 从默认状态点选 `e = 1.6`，按现有代码计算，探针回退到 `(760, 250)`，距离比约为 `2.529`。回退方向上的真实双曲线顶点在画框外，截短极径会使探针离开曲线。用真实曲线点筛选画框内的候选，当前支没有可见点时选择另一支上的可见点，并随画框提示可见范围。验收时依次切换 `e = 0.55、0.99、1.00、1.01、1.60`，拖动探针到画框边缘。在所有可见探针位置，距离比应与滑块一致。 [D4 画板](../src/boards/conics/definitions/unidef.js)
- [x] **明确焦点―准线定义与两种极限。** 写出椭圆 `0 < e < 1`，并注明公式 `d − r cos θ` 用于与焦点位于准线同侧的点，一般距离应取绝对值。固定焦点与准线时，`e → 1` 的曲线在有限视窗内趋近抛物线。固定椭圆的长半轴时，`e → 1⁻` 的椭圆收缩成沿长轴的线段。固定焦点、准线并令 `e → 0` 时，轨迹收缩到焦点，固定长半轴令 `e → 0` 时得到通常的圆。 [D4 讲义](../src/views/conics/definitions/def4.vue)
- [x] **D4c 切换模式时只保留当前提示。** 椭圆分支调用 `hint()`，双曲线分支调用 `hintM()`，两种提示常驻并占据同一行。统一使用一个提示入口，并在椭圆与双曲线之间来回切换验证。双曲线的张口角直接画在同一支对应的两条渐近射线之间。 [D4c 画板](../src/boards/conics/definitions/eshape.js) · [提示实现](../src/lib/board.js)

### 黎曼和 定1

- [x] **让判读和选中的函数、取样方式一致。** 当前选择 `sin x`、`n = 2` 时，左、右端点和都约为 `1.571`，精确值为 `2`，右端点模式却会提示「和数偏大」。将判读建立在当前差值 `Sₙ − I` 上，同时随函数切换精确值公式。图注使用「分割加密时收敛」描述趋势，取样法的误差比较以当前计算结果为准。 [黎曼和画板](../src/boards/calc1/definite/riemannsum.js) · [定积分讲义](../src/views/calc1/definite/f1.vue)
- [x] **加入有向面积例子。** 增加 `y = x` 在 `[-1, 1]` 的示例。用边框、填充和正负标记区分横轴上下的矩形。以中点取样、`n = 4` 验收，轴下和为 `−0.5`，轴上和为 `0.5`，总和为 `0`。可从图注链接到物理的速度—时间图。

### 球的截面 积2

- [x] **区分平面高度、距离与三种位置关系。** 用 `h` 表示带符号的平面高度，用 `d = |h|` 表示球心到平面的距离。按 `d < R`、`d = R`、`d > R` 分别画出截面圆、切点、相离状态。将开篇「截面永远是圆」改为有条件的陈述，半径标签 `r` 放在 `P₀A` 线上，`h = 0` 时收起退化三角形的直角标记。以 `R = 1.4`、`h = 0、±1.4、±1.5` 验证大圆、上下切点与相离。 [球截面画板](../src/boards/solid/measure/spherecutlab.js) · [球截面讲义](../src/views/solid/measure/m2.vue)

### 速度与加速度 力2b

- [x] **让转向和回到起点有各自的标记。** 加速度为负时，速度归零的时刻仍可能在画框外。例如 `v₀ = 2 m/s、a = −0.1 m/s²` 时，`t = 20 s` 才转向，当前视窗为 `0–5.4 s`。图注应说明条件，并将斜率三角形的比值明确写成 `Δv / Δt`。提供 `v₀ = 2 m/s、a = −1 m/s²` 的「观察掉头」预设，在两图上联动标出 `t = 2 s` 的转向和 `t = 4 s` 的回到起点。验收时应能读出 `t = 4 s` 的位移为 `0 m`、路程为 `4 m`。 [运动图像画板](../src/physics/demos/vgraph.js) · [速度与加速度讲义](../src/views/physics/mech/motion2.vue)

## 本轮验证结果

- D4 用离心率从 0.30 到 2.40 的 211 档数据检查了探针读数和画框边界。另验证了双曲线两支切换、键盘微调和 D4c 近极限的几个采样值。

- 力2b 验证了 2 秒转向与 4 秒回到起点。新增「定格 4 秒」可直接查看位移 0 m、路程 4 m。
- 生产构建通过。既有数论脚本报告 71 项通过、8 项失败，在还原本轮共用画板引擎修改的对照运行中结果相同。
