## 图形与知识点的修改清单

### 圆锥曲线 D4 与 D4c

- [x] **D4 保持探针在曲线上。** 从默认状态点选 `e = 1.6`，按现有代码计算，探针回退到 `(760, 250)`，距离比约为 `2.529`。回退方向上的真实双曲线顶点在画框外，截短极径会使探针离开曲线。用真实曲线点筛选画框内的候选，当前支没有可见点时选择另一支上的可见点，并随画框提示可见范围。验收时依次切换 `e = 0.55、0.99、1.00、1.01、1.60`，拖动探针到画框边缘。在所有可见探针位置，距离比应与滑块一致。 [D4 画板](../src/boards/conics/definitions/unidef.js)
- [x] **明确焦点―准线定义与两种极限。** 写出椭圆 `0 < e < 1`，并注明公式 `d − r cos θ` 用于与焦点位于准线同侧的点，一般距离应取绝对值。固定焦点与准线时，`e → 1` 的曲线在有限视窗内趋近抛物线。固定椭圆的长半轴时，`e → 1⁻` 的椭圆收缩成沿长轴的线段。固定焦点、准线并令 `e → 0` 时，轨迹收缩到焦点，固定长半轴令 `e → 0` 时得到通常的圆。 [D4 讲义](../src/views/conics/definitions/def4.vue)
- [x] **D4c 切换模式时只保留当前提示。** 椭圆分支调用 `hint()`，双曲线分支调用 `hintM()`，两种提示常驻并占据同一行。统一使用一个提示入口，并在椭圆与双曲线之间来回切换验证。双曲线的张口角直接画在同一支对应的两条渐近射线之间。 [D4c 画板](../src/boards/conics/definitions/eshape.js) · [提示实现](../src/lib/board.js)

## 画板配色方案的推广

2026-11-25。画板的语义色此前只有亮、暗两套（`conic-diagram` 的 LIGHT / DARK），八套主题与八档预设纸面里，真正换过图形配色的只有「纸面」与「暗夜」。本轮把配色来源接到画板自身，页面主题与页面样式一概不动。

- `conic-diagram.js` 的 `setPalette` 增加第三个参数（方案 id）：预设纸面直接取 `papers.js` 为该档配好的 indigo / blue / green / purple / pink / cyan 与 graphite / alert，墨色也用该档自己的 ink；跟随主题时，暗夜与纸面两套默认主题保持原来的色板不变，其余六套读页面主题的 `--blue / --pink / --green / --purple / --cyan`，墨色、辅助灰与警示红仍按纸面明暗取基础色板；自定义底色保持原样。
- 新增 `--pj-accent`：主题档沿用原来的三条规则（暮夜紫、暖沙橙、其余取主题蓝），观感与改前一致；预设纸面按暖沙橙、薄荷与林深绿、樱粉粉、紫夜紫、墨蓝青，其余蓝。J1 的整板光晕改读这一枚变量，删掉原来按主题写死的两条例外。
- `board.js` 的 `syncTint` 把方案 id 一并交给 `onAppearanceChange`，并用「底色 + 方案」双条件判断是否重算。写入范围只有板根、SVG 与图卡上的 `--pj-*`，不影响页面。
- 未动的部分：其余画板仍走引擎 `COLOR` 的亮、暗两家。要把它们也接上，需要让 `paint()` 按当前方案解析七枚语义色——默认的暗夜与纸面两档变量与现值一致，观感不变，但其余主题与纸面会换色；这一步留到下一批再做。
- 本轮只做了静态核对，浏览器与构建验证留待下一批统一跑。
