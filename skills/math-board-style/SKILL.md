# 数学交互画板样式

先确定这张板要帮助读者看懂哪条数学关系。用参考图提取布局、色彩、线型和光效，保持目标画板自己的坐标、数据和交互语义。

## 画板排布约定

用户说“三角布局”（三角排布）或“默认排布”时，直接按对应方式优化指定画板。这两个名称在各数学章节通用。

- **默认排布**。控件在上，主图居中。数值和判读都放在主图下方，读数框对齐，较长的说明占整行。
- **三角排布**。以[单位圆定义与三角函数线](../../src/boards/trig/unit/unitline.js)为例，控件在上，左侧画图并保留线段、关键点的标注，右侧突出当前角度或参数，按数学关系分组展示实时数值。读数的配色呼应图中的对象，可用对齐的文字和留白区分各组。象限判读、特殊值公式和其他说明放在两栏下方。窄屏时将右栏移到图下、判读之前。

单位圆的右栏先列角度与弧度，再将正弦与余割、余弦与正割、正切与余切分别配对。其他画板按各自的数学量配组。同组读数为奇数时每行三项，偶数时每行两项；单项独占一行。原样式的判读另起一行。优先采用题目指定的同行组合，窄屏按可用宽度减少列数。

已有画板先保留读数相对主图的位置：图右的仍在图右，图下的仍在图下。同行项目顶端和列宽对齐，原样式的判读可两项并排，长判读独占一行。按画板可用宽度减列，桌面、手机、半屏与全屏都要检查公式和上下标是否完整，读数格内避免滚动条。

**图例位置**。新建或修改画板时，将曲线、坐标、点和有向线段的图例放进主图的圆角虚线框。图例字号略小于主要标注，紧贴绘图区排布，按实际行数留出空间。颜色和实虚线与图中对象对应。中文图例用宋体，数字、拉丁或希腊字母、上下标、单位和数学表达式用 LaTeX 渲染。屏显与导出沿用相同字体和公式。随预设和图层开关更新。窄屏可换行，避免盖住坐标轴、函数线标注或拖点；导出图片时也应包含图例。

### 读数与公式的三种样式

**三角样式**沿用单位圆的数值栏：彩色量名在上、数值在下，以留白和细线对齐相关量。图右优先用三角样式；图下可以用三角样式对照同组数值，也可以用信息样式突出结果。默认排布与三角排布描述图和控件的位置，样式描述每项读数的外观。

**信息样式**适用于重要结果、判定、性质和规律。判定类优先用信息样式，与数值组分行。判读框占整行，短标签独占框内第一行，结论从下一行开始，与标签左缘对齐。判读、性质等信息框的中文标签和说明优先使用宋体，公式沿用 KaTeX 字体。短结论尽量一行读完。窄屏允许在语义或公式边界换行，保留必要条件、完整公式和可读字号。

参考 `Screenshot_2026-11-27-11-30-33-75_149003a2d400f6adb210d7e357a3a646.jpg` 右侧“考点板”。标签使用实际数学量名称，短标签在上，公式或数值在下。卡片左缘用一条上下留白的细亮线，左缘仅保留微弱光晕，标签用实色底。浅淡的同色底光向右平滑衰减，右端融入画板纸色。暗纸提亮左缘，浅纸以主题深色形成轮廓。文字保持清晰，异常值同时用文字和状态色说明。

实例见[保序变形](../../src/boards/inequalities/prop/keeporder.js)。将 `data-reading-style="info"` 设在判读栏或数值组，应用[信息样式](../../src/boards/info-readings.css)。数值组按奇三偶二、单项独占的规则排列。

**轻量样式**用于起始公式、推导结果和简短的读图提示。使用小圆角与约 8% 的主题色平底，标题用宋体，数学内容用 KaTeX。相邻步骤可用主题蓝和主题金区分，保持相同的内边距、字号和左缘。例见积化和差的“正弦和差公式”和“两边同除以 2”。共用样式为 `data-reading-style="light"`。

## 硬性要求（新板一律逐条对照）

1. **版式**：按上面的排布约定放置主图、读数和判读。图下读数紧贴主图、**不画分隔横线**。读数按内容排 2–3 列，长判读占两格或整行，窄屏落成单列；整组内容在虚线框内纵向居中，顶部不留大块空白。
2. **外框**：整张图套一只圆角虚线框，`stroke` 取当前方案的强调色（`plotInk.accent` / `--pj-accent`），虚线 `7 6`、圆角 16 左右；框要包住主图与探针读数。
3. **取色**：语义色从当前方案取**实色**（把 `--pj-*` 读成 hex/rgba 再画），深纸提高填充率、浅纸收回去；默认「暗夜 / 纸面」两档保持原来的色板，其余六套主题与八档预设纸面各自换色。自定义底色退回基础亮/暗两套。
4. **重点点位**。新建或修改画板时，主动检查本次涉及的各个预设。突出当前探针、对应像点，以及本例用来说明结论的顶点、切点、对称中心或反例点。用当前主题实色调用 `glowDot(B, p, color, 8, 3.5)`，绘制无黑边的实心小光点。光晕半径通常取 7–9 个画板单位，光芯取 3–4。重合点只绘制一圈光晕。普通参考点用素点，表示排除值的端点保留主题色空心圈，可拖点保留透明命中区。
5. **状态色**：否定/「不符合」的读数给 `warn` 类，并在该板 CSS 里把边框、左边条、文字、10% 底覆盖成红色（全局 `chip.warn` 是黄色）；肯定状态用绿。
6. **图内文字**：只留点名、刻度、命题式、公式、表格数据这类短标注；说明性长句、操作提示、重复的逐点读数移到徽章或图注；`k=`、个数等数字用 LaTeX 混排。
7. **防重叠**：标签与虚线框、轴线、其他标签至少留 15–20px；放不下就删重复标签（公式在徽章里已有的，图内不再写第二遍）。

选中标记固定在例题框内侧靠左的位置，编号与文字独立居中。窄屏分两行时，让光点与编号行对齐。颜色取当前画板主题色。数学读数框随内容增高，窄屏允许公式之间换行，保持分式和上下标完整可见。

## 修改流程

1. 找到章节视图、画板绘制入口和已有样式。记录初始画面、至少一个有代表性的切换状态，以及当前主题和显示模式。
2. 看参考图的全貌与局部，识别整板底色、主图、辅助线、关键点、判读区与导航；**只借鉴视觉关系，不照搬视频字幕、头像等装饰**。
3. 先改一张板：按用户指定的排布确定版式，未指定时沿用该画板的布局，套虚线外框，再接色板与发光点。
4. 把图内长句移出：并入 `.chips` 徽章、图注或页面正文；徽章按内容排 2–3 列，否定项标红。
5. 在真实页面检查数值与落点，再验主题、纸面、屏宽、半屏/全屏、点击热区与导出；发现字压线、框撞字、光晕发黑，优先修那一层。

## 已知坑

- **SVG presentation attribute 里的 `var()` 不可靠**：`fill`、`stop-color` 都可能解析失败。关键颜色先读成实色再画，或写成内联 `style`。
- **`plotInk` 键名要对得上**：有 `amber` 也有 `gold`（现为别名）；新增键名后全局搜一遍，否则 `undefined` 会让把手退回白色、光晕变黑。
- **掩膜里的 `#ffffff` / `#000000` 是亮度合成的原始色**，不要换成语义色。
- **`buildMasks()` 会清空 defs**（Y2 右墙、Y3 换预设）：任何依赖 defs 的效果都要在重建函数末尾补回。
- **Vite 热更新不会重建已挂载的画板**：验收前强刷页面；必要时重启 dev 服务器；可用 `curl localhost:5173/src/…` 确认服务端模块是新版。
- **`dist/` 会被 `npm run build` 清空**：参考图、skill 与说明不要只放在 `dist/tmp`、`dist/skills`。

## 验收清单

- 主题：暗夜、纸面、暖沙、樱粉、薄荷/云紫各看一遍；纸面至少浅纸、深纸各一档。
- 宽度：1440 与 393；半屏、全屏各进一次；浮层退出后版面不跳。
- 交互：拖动、点字母区域（不能只点边框）、切预设、扫掠/动画。
- 状态：ok 绿、warn 红、未选中点无光；选中点有金色/绿色渐隐，不是黑晕。
- 导出：PNG 与页面颜色一致，无黑块、无丢字。
- 控制台无报错；标签不压框、不压轴、互不重叠。
